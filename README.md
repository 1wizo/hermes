# HERMES

**A browser built for speed, privacy, and simplicity.**

HERMES is an independent Linux desktop browser project built around the Chromium Embedded Framework (CEF), GTK4, and C++.

Inspired by the clean, distraction-free experience of modern browsers like Zen, HERMES aims to combine a carefully designed interface with Chromium's mature web compatibility, strong security foundations, and efficient resource management.

### Philosophy

- **Speed first:** Minimize overhead, unnecessary processes, and resource consumption.
- **Privacy by design:** Prioritize tracking protection, fingerprinting resistance, and secure browsing.
- **Minimalism:** A clean, focused interface without unnecessary features or visual clutter.
- **Native Linux experience:** Built with GTK4 and designed with Linux desktop environments in mind.
- **Security without compromise:** Preserve Chromium's sandboxing and site-isolation protections.

### Technology

- **Language:** C++
- **Interface:** GTK4
- **Browser engine:** Chromium via CEF
- **Build system:** CMake

### Vision

HERMES aims to deliver a fast, lightweight, and privacy-conscious browsing experience for Linux users without sacrificing modern web compatibility or security.

*Less overhead. More control. A better browsing experience.*
